# User Stories — Smart Clinic Management System

## Admin

1. **As an admin**, I want to log into the admin portal with a username and
   password, so that I can manage the clinic's doctors and system data securely.
2. **As an admin**, I want to add a new doctor's profile (name, specialty,
   email, phone, available times), so that patients can book appointments
   with them.
3. **As an admin**, I want to remove a doctor who no longer works at the
   clinic, so that patients can't book appointments with them.
4. **As an admin**, I want to view all upcoming appointments across the
   clinic, so that I can monitor daily patient load.
5. **As an admin**, I want to run reports (e.g. doctor with most patients
   per month), so that I can plan staffing.

## Patient

1. **As a patient**, I want to register an account with my email and
   password, so that I can log in and manage my appointments.
2. **As a patient**, I want to search for a doctor by name or specialty, so
   that I can find the right doctor for my needs.
3. **As a patient**, I want to view a doctor's available time slots, so
   that I can choose a convenient appointment time.
4. **As a patient**, I want to book an appointment with a doctor, so that I
   can receive care on a specific date and time.
5. **As a patient**, I want to view my upcoming and past appointments, so
   that I can keep track of my visit history.
6. **As a patient**, I want to view prescriptions issued to me, so that I
   know what medication to take.

## Doctor

1. **As a doctor**, I want to log into the doctor portal with my email and
   password, so that I can access my schedule securely.
2. **As a doctor**, I want to view my list of appointments for a given
   day, so that I know who I'm seeing and when.
3. **As a doctor**, I want to set and update my available time slots, so
   that patients can only book times I'm actually free.
4. **As a doctor**, I want to write a prescription for a patient after an
   appointment, so that the patient has a record of their medication.
5. **As a doctor**, I want to view a daily appointment report, so that I
   can prepare for the day ahead.
